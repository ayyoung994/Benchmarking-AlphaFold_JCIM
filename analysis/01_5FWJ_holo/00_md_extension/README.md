# MD Extension

This directory contains replica-specific shell scripts used to extend selected MD production runs for the `01_5FWJ_holo` system from 20 ns to 60 ns before downstream analysis.

## Contents

- `extend_md_rep2.sh` — extension of Replica 2 production MD to 60 ns
- `extend_md_rep3.sh` — extension of Replica 3 production MD to 60 ns

## Note on Replica 1

The original MD production files for Replica 1 were unavailable. Therefore, Replica 1 was regenerated by rerunning the production MD simulation rather than continuing from an existing checkpoint-based extension workflow.

Because the original continuation files were not available, no `extend_md_rep1.sh` file is included in this directory.

## Purpose

These scripts document the continuation workflow used for replicas that were extended from the original 20 ns production run to a final 60 ns trajectory.

## Notes

- These scripts are only included for replicas that were extended using the available checkpoint-based workflow.
- Replica 1 followed a different recovery path because the original production files were lost.
