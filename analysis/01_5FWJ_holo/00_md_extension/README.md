# MD Extension

This directory contains replica-specific shell scripts and execution log files used to extend selected production MD runs for the `01_5FWJ_holo` system from 20 ns to 60 ns before downstream analysis.

The folder label `01_5FWJ_holo` is retained for workflow continuity. In the manuscript, this system corresponds to the **5FWJ metal-retained** receptor setup.

## Directory contents

- `scripts/` — shell scripts used to continue selected production MD runs
- `logs/` — GROMACS log files generated during the extended production runs
- `README.md` — overview of the MD extension workflow and file organization

## Included scripts

- `scripts/extend_md_rep2.sh` — production extension workflow for Replica 2
- `scripts/extend_md_rep3.sh` — production extension workflow for Replica 3

## Included log files

- `logs/md_rep2.part0003.log` — execution log for the extended production run of Replica 2
- `logs/md_rep3.part0002.log` — execution log for the extended production run of Replica 3

## Replica 1

Replica 1 is not represented by an extension script in this directory because the original MD production files were unavailable. As a result, replica 1 was regenerated by rerunning the production MD simulation rather than extended from an existing checkpoint-based continuation workflow.

## Purpose

These files document the checkpoint-based continuation workflow used to extend selected original 20 ns production runs and generate the final 60 ns trajectories used for subsequent preprocessing and analysis.

## Notes

- The shell scripts preserve the command-line workflow used for each replica that underwent checkpoint-based extension.
- The log files provide execution records for the extended MD runs.
- Part numbers in the log filenames reflect the original continuation history and may differ among replicas.
- Replica 1 followed a different recovery path because the original production files were unavailable.
- The internal label `holo` is retained in file and folder names for workflow continuity. In the manuscript, this system is described as **5FWJ metal-retained**.
