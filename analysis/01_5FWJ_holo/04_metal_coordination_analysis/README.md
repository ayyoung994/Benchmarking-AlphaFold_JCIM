# Metal Coordination Analysis

## Overview

This directory contains the **metal coordination analysis workflow** for the **5FWJ holo** system in the KDM5C benchmarking study.

The purpose of this analysis is to evaluate the stability of **Mn²⁺ coordination** during molecular dynamics simulations by tracking the **minimum distances** and **contact persistence** between the bound Mn²⁺ ion and three key coordinating residues in the JmjC catalytic pocket:

- **His514 (NE2)**
- **Glu516 (OE2)**
- **His602 (NE2)**

This workflow was applied only to the **crystal-structure-based holo reference system (5FWJ holo)**, where the catalytic metal ion is explicitly present in the binding site.

---

## Directory Structure

- `inputs/`  
  Replica-specific index files used for metal coordination analysis.  
  These include:
  - `jmjc_2_rep*.ndx`: replica-specific JmjC analysis index files used as starting inputs
  - `metal_coord_rep*.ndx`: derived index files containing Mn²⁺ and coordinating-residue atom groups for distance/contact analysis

- `scripts/`  
  Shell scripts used to generate the metal coordination index groups and run the Mn²⁺ coordination analysis.

- `raw_outputs/`  
  Raw `.xvg` files generated by `gmx mindist`, including per-replica minimum-distance traces and contact traces for Mn²⁺ against each coordinating residue.

- `processed_tables/`  
  Processed summary tables derived from the raw outputs, including replica-level and across-replica statistics.

- `README.md`  
  Documentation describing the workflow, folder organization, required inputs, and expected outputs.

## Workflow Summary

### 1. Preparation of metal coordination index files

Replica-specific JmjC index files (`jmjc_2_rep*.ndx`) were used to generate dedicated metal coordination index files for Mn²⁺ analysis.

The resulting `metal_coord_rep*.ndx` files include groups for:

- the **Mn²⁺ ion**
- **His514 NE2**
- **Glu516 OE2**
- **His602 NE2**

Depending on the script version, additional donor-atom or pocket-related groups may also be included for screening or verification.

Script:
- `scripts/01_make_metal_coord_index.sh`

Input:
- `inputs/jmjc_2_rep*.ndx`

Output:
- `inputs/metal_coord_rep*.ndx`

---

### 2. Mn²⁺–residue distance and contact analysis

Minimum distances and contact traces were calculated using `gmx mindist` for each replica-specific metal coordination index file.

For each replica, the following Mn²⁺–residue pairs were analyzed:

- **Mn²⁺–His514 (NE2)**
- **Mn²⁺–Glu516 (OE2)**
- **Mn²⁺–His602 (NE2)**

Script:
- `scripts/02_metal_coordination_mindist.sh`

Representative outputs:
- `raw_outputs/dist_MN_HIS514_NE2_*.xvg`
- `raw_outputs/contact_MN_HIS514_NE2_*.xvg`
- `raw_outputs/dist_MN_GLU516_OE2_*.xvg`
- `raw_outputs/contact_MN_GLU516_OE2_*.xvg`
- `raw_outputs/dist_MN_HIS602_NE2_*.xvg`
- `raw_outputs/contact_MN_HIS602_NE2_*.xvg`

## Output Description

- Mn²⁺–His514 contact trace
- Mn²⁺–Glu516 minimum distance
- Mn²⁺–Glu516 contact trace
- Mn²⁺–His602 minimum distance

### Processed outputs

The `processed_tables/` folder may contain summary tables such as:

- per-replica mean distance
- per-replica standard deviation
- minimum observed distance
- contact persistence summaries
- across-replica summary statistics

---

## Notes

- Distance traces report the **minimum Mn²⁺–atom distance** between the selected groups over time.
- Contact traces report whether the Mn²⁺–residue pair satisfies the distance cutoff defined in the `gmx mindist` calculation.
- Replica-specific index files were used to preserve consistency with each simulation setup.
- This workflow was applied only to the **5FWJ holo** system because explicit catalytic metal coordination was evaluated only in the metal-bound crystal-structure-based reference model.

---

## Scripts

- `scripts/01_make_metal_coord_index.sh`  
  Generates replica-specific metal coordination index files from the corresponding JmjC index files.

- `scripts/02_metal_coordination_mindist.sh`  
  Runs `gmx mindist` to calculate Mn²⁺–residue minimum-distance and contact traces.
