# Metal-Associated Distance Analysis

## Overview

This directory contains the metal-associated distance analysis workflow for the `01_5FWJ_holo` system in the KDM5C receptor-setup sensitivity study.

The folder label `01_5FWJ_holo` is retained for workflow continuity. In the manuscript, this system corresponds to the **5FWJ metal-retained** receptor setup.

The purpose of this analysis is to monitor Mn²⁺–residue distance behavior during molecular dynamics simulations by tracking distances between the pocket-proximal Mn²⁺ ion and selected residue atoms in the JmjC catalytic pocket:

- **His514 (NE2)**
- **Glu516 (OE2)**
- **His602 (NE2)**

This workflow was applied only to the **5FWJ metal-retained** system because crystallographic metal ions were retained only in this experimental receptor setup.

---

## Directory Structure

- `inputs/` — replica-specific index files used for metal-associated distance analysis

- `scripts/`  — shell scripts used to generate metal-distance index groups and run Mn²⁺–residue distance/contact analyses
  
- `raw_outputs/`  — raw .xvg files generated by gmx mindist, including per-replica distance traces and contact traces

- `processed_tables/` — processed summary tables derived from raw outputs, including replica-level and across-replica statistics

- `README.md`  — documentation describing the workflow, folder organization, required inputs, and expected outputs

## Workflow Summary

### 1. Preparation of metal coordination index files

Replica-specific JmjC index files, `jmjc_2_rep*.ndx`, were used to generate dedicated index files for Mn²⁺–residue distance analysis.

The resulting `metal_coord_rep*.ndx` files include groups for:

- **Mn²⁺ ion**
- **His514 NE2**
- **Glu516 OE2**
- **His602 NE2**

Depending on the script version, additional donor-atom or pocket-related groups may also be included for screening or verification.

Script:
- `scripts/01_make_metal_coord_index.sh`

Input:
- `inputs/jmjc_2_rep*.ndx`

Output:
- `inputs/metal_coord_rep*.ndx`

---

### 2. Mn²⁺–residue distance and contact analysis

Minimum-distance traces and contact traces were calculated using `gmx mindist` for each replica-specific metal-distance index file.

For each replica, the following Mn²⁺–residue atom pairs were analyzed:

- **Mn²⁺–His514 (NE2)**
- **Mn²⁺–Glu516 (OE2)**
- **Mn²⁺–His602 (NE2)**

Script:
- `scripts/02_metal_coordination_mindist.sh`

Representative outputs:
- `raw_outputs/dist_MN_HIS514_NE2_*.xvg`
- `raw_outputs/contact_MN_HIS514_NE2_*.xvg`
- `raw_outputs/dist_MN_GLU516_OE2_*.xvg`
- `raw_outputs/contact_MN_GLU516_OE2_*.xvg`
- `raw_outputs/dist_MN_HIS602_NE2_*.xvg`
- `raw_outputs/contact_MN_HIS602_NE2_*.xvg`

## Notes

- Distance traces report the minimum Mn²⁺–atom distance between the selected groups over time.
- Contact traces report whether the Mn²⁺–residue atom pair satisfies the distance cutoff defined in the `gmx mindist` calculation.
- Replica-specific index files were used to preserve consistency with each simulation setup.
- This workflow was applied only to the **5FWJ metal-retained** receptor setup because Mn²⁺ was explicitly retained only in this system.
- These analyses are provided to monitor metal-associated distance behavior under the applied nonbonded metal treatment.
- The results should not be interpreted as definitive validation of native catalytic metal coordination, because no bonded metal–residue coordination restraints were applied during production MD.
- The internal label `holo` is retained in file and folder names for workflow continuity. In the manuscript, this system is described as **5FWJ metal-retained**.
