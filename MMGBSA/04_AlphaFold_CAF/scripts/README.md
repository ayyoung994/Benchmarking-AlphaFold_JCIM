# MM/GBSA Execution Scripts

This directory contains shell scripts used to run MM/GBSA endpoint-energy calculations for the `04_AlphaFold_CAF` system.

The folder label `04_AlphaFold_CAF` corresponds to the **custom AlphaFold-derived KDM5C receptor model** used in the manuscript. This receptor setup is referred to as **CAF**.

## Contents

- `run_mmgbsa_rep1.sh` — MM/GBSA execution script for replica 1
- `run_mmgbsa_rep2.sh` — MM/GBSA execution script for replica 2
- `run_mmgbsa_rep3.sh` — MM/GBSA execution script for replica 3
- `README.md` — description of the scripts in this directory

## Workflow summary

The MM/GBSA workflow for each replica consisted of:

1. preparing receptor and ligand group selections from `jmjc.ndx`
2. preprocessing the trajectory using `gmx trjconv`
3. using the shared `mmpbsa.in` input file
4. running `gmx_MMPBSA` with the appropriate topology, trajectory, and group definitions
5. generating replica-specific MM/GBSA output and log files

## Notes

- The same MM/GBSA settings were used for all three replicas of the `04_AlphaFold_CAF system` unless otherwise noted.
- For this **CAF receptor setup**, the receptor group was defined from the extracted JmjC region.
- No crystallographic metal-ion groups were included in the MM/GBSA receptor definition for this AlphaFold-derived system.
- The ligand group used in the MM/GBSA workflow was `DOL`.
- Replica-specific scripts differ mainly in the input trajectory and structure files used for each run.
- Shared MM/GBSA input files are stored in the corresponding input/ directory.
- MM/GBSA values generated by these scripts are protocol-dependent endpoint-energy descriptors and should not be interpreted as absolute binding affinities or evidence of ligand potency.
